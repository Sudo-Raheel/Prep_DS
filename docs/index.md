Some topics to learn for puzzles Counting & Combinatorics Probability Expected Value Recursive Probability Logic Puzzles Game Theory Statistics & Estimation Fermi Estimation Optimization Number Theory Geometry Probability

Read up on scorecard basics beforehand: WOE/IV binning, the Gini and KS statistics, PSI for population stability, and why logistic regression still dominates regulated underwriting despite worse raw performance. It’s a few hours of reading, and knowing why the field favours interpretable models there would let you discuss the gap intelligently rather than just acknowledging it.
