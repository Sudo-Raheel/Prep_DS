    Cheat sheet

    Senior Data Scientist Interview Mathematics\ 2-page high-yield syllabus — topics and subtopics only

    2

    1. Probability — Essential

    • Conditional probability; independence; Bayes theorem; law of total probability

    • Permutations, combinations, complements; sampling with/without replacement

    • Random variables; PMF/PDF/CDF; transformations

    • Expectation; conditional expectation; variance; covariance; correlation

    • Bernoulli, Binomial, Normal, Poisson, Exponential, Beta, Hypergeometric

    • Law of Large Numbers; Central Limit Theorem; normal approximation

    • Indicator variables; linearity of expectation; probability trees

    2. Statistical Inference — Essential

    • Estimators: bias, variance, consistency, standard error

    • Likelihood; log-likelihood; Maximum Likelihood Estimation

    • Sampling distributions: \(z\), \(t\), chi-square, \(F\)

    • Confidence intervals for means, proportions, and differences

    • Hypothesis testing; \(p\)-value; Type I/II errors; power; effect size; MDE

    • \(z\)-test vs. \(t\)-test; paired vs. independent; Welch test

    • Chi-square tests; ANOVA; multiple-comparison control

    • Bootstrap and permutation tests

    3. A/B Testing and Experimentation — Essential

    • Estimand; randomization unit; treatment/control; intention-to-treat

    • Primary metric; guardrails; experiment validity

    • Sample size; power; MDE; effect estimate + confidence interval

    • Sample Ratio Mismatch; balance and instrumentation checks

    • Peeking / optional stopping; sequential-testing basics

    • Factorial design; interaction effects; multiple variants

    • CUPED / covariate adjustment; variance reduction

    • Heterogeneous treatment effects; subgroup multiplicity

    • Interference; SUTVA; cluster randomization; switchbacks

    4. Linear Algebra — Essential

    • Vectors; dot product; norms; Euclidean distance; cosine similarity

    • Matrices; transpose; inverse; rank; trace; determinant

    • Linear systems; projections; least squares; pseudoinverse

    • Eigenvalues/eigenvectors; positive-semidefinite matrices

    • SVD; low-rank approximation; PCA

    • Covariance/correlation matrices; condition number; ill-conditioning

    5. Calculus and Optimization — Essential

    • Partial derivatives; chain rule; gradient; Jacobian; Hessian

    • Convexity; local/global optimum; first/second-order conditions

    • Gradient descent; SGD; mini-batches; learning rate

    • Momentum; Newton-method intuition

    • Lagrange multipliers; constrained optimization

    • \(L_1\) vs. \(L_2\) geometry and regularization

    6. Linear Regression — Essential

    • OLS; normal equations; projection interpretation

    • Assumptions: linearity, exogeneity, independence, homoscedasticity

    • Coefficient SEs; confidence intervals; \(t\)-tests

    • Residual analysis; heteroscedasticity; robust standard errors

    • Multicollinearity; VIF; unstable coefficients

    • Interactions; polynomial terms; coefficient interpretation

    7. Regularization and Logistic Regression — Essential

    • Ridge: \(L_2\) shrinkage; LASSO: \(L_1\) sparsity; Elastic Net

    • Regularization strength; scaling; cross-validation; bias-variance

    • Logistic regression: odds, log-odds, sigmoid

    • Bernoulli likelihood; binary cross-entropy; gradient

    • Softmax regression; multiclass cross-entropy

    8. Core ML Mathematics — Essential

    • Empirical risk minimization; objective and loss functions

    • Bias-variance trade-off; underfitting vs. overfitting

    • Train/validation/test error; leakage; generalization

    • Cross-validation: stratified, grouped, and time-aware

    • Missing data: MCAR, MAR, MNAR; imputation implications

    • Class imbalance; weighting/resampling; threshold choice

    9. Trees, Random Forest, Boosting — Essential

    • Decision-tree splits; entropy; information gain; Gini impurity

    • Regression-tree squared-error reduction

    • Bagging and variance reduction

    • Random Forest: bootstrap; feature subsampling; OOB error

    • Boosting as additive/sequential learning

    • Gradient boosting: residual / negative-gradient fitting

    • XGBoost: gradient/Hessian intuition; regularized objective

    10. Model Evaluation — Essential

    • Confusion matrix; accuracy; precision; recall; specificity; F1

    • ROC-AUC; Precision-Recall curve; Average Precision

    • MAE; MSE; RMSE; \(R^2\)

    • Log loss; Brier score; calibration

    • Threshold selection from asymmetric cost / expected utility

    • Slice/segment evaluation; offline vs. online metrics

    11. Clustering and Dimensionality Reduction — High Yield

    • \(k\)-means objective; Lloyd algorithm; convergence; \(k\)-means++

    • Choosing \(k\); elbow and silhouette

    • Gaussian Mixture Models; EM algorithm

    • DBSCAN intuition

    • PCA; explained variance; SVD connection

    12. Time Series / Forecasting — Senior DS Core

    • Trend; seasonality; stationarity; differencing

    • Autocorrelation; partial autocorrelation

    • AR, MA, ARIMA; exponential smoothing / Holt-Winters

    • Rolling / expanding-window validation

    • MAE, RMSE, MAPE; quantile / pinball loss

    • Temporal leakage and drift

    13. Causal Inference — Senior-Level

    • Correlation vs. causation; confounding; selection bias

    • Potential outcomes; ATE and ATT

    • DAG intuition; backdoor paths; collider bias

    • Propensity scores; matching / weighting intuition

    • Difference-in-Differences; parallel-trends assumption

    • Instrumental variables; regression discontinuity intuition

    14. Bayesian Statistics — Core Only

    • Prior; likelihood; posterior; posterior predictive

    • MAP vs. MLE

    • Beta-Bernoulli / Beta-Binomial intuition

    • Credible interval vs. confidence interval

    15. Deep Learning Math — Targeted Only

    • ReLU, sigmoid, tanh, softmax

    • Cross-entropy / negative log-likelihood

    • Chain rule; backpropagation

    • SGD, momentum, Adam; weight decay

    • Vanishing/exploding gradients; initialization

    • CNN: convolution, stride, padding, receptive field

    • Attention: queries, keys, values; scaled dot-product attention

    • Transformer basics; embeddings; cosine similarity

    • LoRA / QLoRA: low-rank adaptation concept

    16. Probability / Math Interview Drills

    • Coins, dice, cards; complements; conditional probability

    • Bayes posterior puzzles

    • Sampling without replacement; Hypergeometric reasoning

    • Expected value with indicator variables

    • Weighted / reservoir sampling

    • Geometric probability; simple Markov-state problems
