# Prep DS

Data Science interview prep notes: probability, statistics, classification, model evaluation, SQL, system design and puzzles.

- **Read online:** enable GitHub Pages (branch `gh-pages`) and the site is served at `[https://sudo-raheel.github.io/Prep_DS/](https://sudo-raheel.github.io/Prep_DS/)`.
- **Read on GitHub:** browse [`docs/`](docs/), where math and tables render natively.
- **Run locally:** `pip install -r requirements.txt && mkdocs serve`
- **Original LaTeX sources:** [`archive/`](archive/)

Notes live in `docs/`; pushing to `main` redeploys the site via GitHub Actions.
